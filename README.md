# SpaceX Applied Data Science Capstone

## Project Overview

This project analyzes SpaceX Falcon 9 launch data and investigates
the factors associated with successful first-stage landings.

## Project Objectives

- Collect SpaceX launch data
- Perform data wrangling
- Perform exploratory data analysis
- Analyze the data using SQL
- Build interactive maps using Folium
- Build an interactive Plotly Dash dashboard
- Build and compare machine learning classification models

## Project Workflow

1. Data Collection
2. Web Scraping
3. Data Wrangling
4. Exploratory Data Analysis
5. SQL Analysis
6. Interactive Mapping
7. Plotly Dash Dashboard
8. Predictive Analysis
9. Final Presentation

## Machine Learning Models

- Logistic Regression
- Support Vector Machine
- Decision Tree
- K-Nearest Neighbors
